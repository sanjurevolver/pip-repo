# Security policy

## Supported versions

The project currently supports Python 3.11, 3.12, and 3.13.

## Reporting a vulnerability

Please do not report security issues publicly in GitHub issues.

Instead, contact the maintainer privately through the repository owners or via the GitHub security reporting flow for the project.

Please include:

- the affected version
- a description of the issue
- reproduction details or a minimal example
- the impact and severity you expect

We will review reported issues promptly and coordinate a fix and disclosure plan.

## Responsible disclosure

We ask users to give maintainers a reasonable opportunity to investigate and remediate issues before public disclosure.
